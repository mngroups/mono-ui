# Numbers

Indonesian (`id-ID`) formatting: `.` groups thousands, `,` marks decimals.

```ts
import { formatIndonesianNumber, formatDecimalIndonesian, formatValue } from "@mono/utils";
```

---

## Formatting

| Function | Use for |
| --- | --- |
| `formatIndonesianNumber(value, options?)` | Any number; `options` are `Intl.NumberFormatOptions` |
| `formatDecimalIndonesian(value, maxDigits)` | Display values: up to `maxDigits` decimals, trailing zeros dropped |
| `formatFixedIndonesian(value, digits)` | Fixed width, e.g. coordinates |
| `formatDisplayNumber(value)` | Numbers or numeric strings from the API (`"1234.50"`); non-numeric strings come back unchanged |

## Chart values

`detectUnit(value, key?)` guesses a unit from the series key (`percent`/`rate` → percent, `cost`/`revenue` → currency) or, without a hint, from the value (0–1 → percent, otherwise ton). `formatValue(value, unit)` renders it; `formatK` keeps two decimals for axis ticks.

  rows={[

    { code: "detectUnit(12480)", result: detectUnit(12480) },
