# @mono/utils

Framework-agnostic helpers shared by MoNo apps and used inside `@mono/ui`: class names, Indonesian number formatting, WITA dates, and a few string and URL guards. No React, so they also run on the server and in Node scripts.

```bash
pnpm add @mono/utils
```

```ts
import { cn, formatIndonesianNumber, witaDateString } from "@mono/utils";
import dayjs from "@mono/utils/dayjs";
```
