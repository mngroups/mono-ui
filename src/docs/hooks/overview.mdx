# @mono/hooks

React hooks shared by MoNo apps and used inside `@mono/ui`. Every hook is client-only (`"use client"` in the built files).

```bash
pnpm add @mono/hooks @mono/utils
```

Peers: `react` 19+. Optional, only for their subpath: `next` for `@mono/hooks/next`, `zustand` + `react-hook-form` for `@mono/hooks/form-draft`.

## Testing in an app

Inline the packages in Vitest so `vi.mock("next/navigation")` reaches them, and mock `@mono/hooks` partially:

```ts
// vitest.config.ts
test: { server: { deps: { inline: [/@mono\//] } } }

// a test
vi.mock("@mono/hooks", async (importOriginal) => ({
  ...(await importOriginal<typeof import("@mono/hooks")>()),
  useIsMobile: () => true,
}));
```
