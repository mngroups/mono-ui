# Colors

Components never use raw colours. They use semantic tokens (CSS variables) that `styles.css` defines for light and dark, and Tailwind utilities generated from them (`bg-primary`, `text-muted-foreground`, …). Switch the **Mode** in the toolbar: the values below update live.

## Brand

Set in `theme-default.css`. Override these four to rebrand; everything below derives from them.
